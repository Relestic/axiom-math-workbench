Axiom 公理 · Windows 免安装分享版

一、如何打开
1. 将整个 ZIP 解压到普通文件夹。不要在压缩包内部直接运行。
2. 双击“启动 Axiom.cmd”。浏览器会自动打开本机页面。
3. 使用时保持启动窗口开启；关闭窗口或按 Ctrl+C 可停止。

适用 Windows x64 电脑，需要已有浏览器。不需要安装 Node.js、npm 或下载依赖。
默认地址：http://127.0.0.1:5174/
如果没有自动打开浏览器，请复制这个地址打开。
若提示端口占用，先关闭原有 Axiom 服务；也可在 .env 中设置 AXIOM_PORT=5186。
本程序只监听本机，不会发布成互联网网站。

二、可以做什么
打开“图像探索”，可输入 sin(a*x^2)、exp(-x^2) 或 x < 0 ? -x : x^2。
参数自动形成滑块，最多比较 4 条曲线；可以切换连续性、导数、定积分、Taylor 工具。
支持定义域与坐标范围设置、撤销、保存观察。经典示例、教材卡片、练习和笔记仍可使用。
公式编辑、绘图和本地练习可以离线运行；外部参考链接和 AI 对话需要联网。
有限采样与数值结果不构成数学证明；本版不是完整课程或自动证明系统。

三、如何配置 AI
1. 将启动文件旁的“.env.example”复制一份，改名为“.env”。
   请在资源管理器中显示文件扩展名，确认没有误保存成 .env.txt。
2. 用记事本编辑，填入自己的服务商配置：

AI_BASE_URL=https://你的服务地址/v1
AI_MODEL=服务商提供的模型标识
AI_API_KEY=你的密钥
AI_JSON_MODE=true

3. 保存，关闭启动窗口，再双击启动文件。

接口需要兼容 Chat Completions；根地址不要包含 /chat/completions。
若服务商不支持 JSON 模式，将 AI_JSON_MODE 改为 false 后重启。
程序显示“模型已配置”只表示已读取配置；成功发送一次才能确认实际连通性。
未配置 AI 时仍可手动编辑公式，不会出现假模型回答。
AI 按服务商的规则和账户额度计费，本分享包不提供密钥或免费额度。
发送对话时，只向所配置的服务商发送当前函数场景和最近对话，不上传教材、笔记或作答。

四、记录与再次分享
记录保存在当前电脑的浏览器中，不会跟随 ZIP 同步到另一台电脑。
清除浏览器站点数据会删除本地记录；重要笔记和作答请通过页面的导出功能保存。
不同端口属于不同的浏览器存储空间；修改端口不会迁移原有记录。
请分享原始 ZIP。若重新压缩自己的使用目录，务必排除 .env，避免分享模型密钥。
本原始分享包不包含密钥、用户笔记、作答或浏览器学习数据。
