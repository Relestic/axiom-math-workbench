Axiom 公理 · 完整版 Windows x64 免安装分享包

【启动】
完整解压 ZIP，再双击“启动 Axiom.cmd”。不要在压缩包内直接运行。
首次启动会创建本机数据库和全新的演示数据，稍等几秒浏览器会打开。
默认地址：http://127.0.0.1:5186/
使用时保留启动窗口；关闭窗口或按 Ctrl+C 停止服务。
若端口被占用，可在 backend/.env 中设置 AXIOM_PORT=5187，然后重启。
包内自带 Python 和所需依赖，不需安装 Python、Node.js 或下载依赖。
仅支持 Windows x64 电脑；通过本机浏览器使用，不会自动公开到互联网。

【包含的功能】
教材学习主页面：导入自己的 .docx，显示原文章节与段落；自动识别数学词并在原文字词上生成图像链接，点击进入图像，返回原段落。
设置 → AI 规则与示例：编辑识别/图像/问答规则，保存版本、恢复默认、测试一段原文，并保存纠正示例。
包内提供明确标注“非用户原文”的 Word 测试讲义（含公式、表格、图片和狄利克雷案例）；旧 PDF 阅读器仍可从兼容入口打开。
练习题库：提示、完整解答、AI 讨论、提交后 AI 批改、历史作答。
还有学习工作台、练习可视化、知识地图、三维曲面实验室、笔记。
练习页有“和 AI 讨论”和“提交答案”两个独立按钮：讨论只追问，提交才评分。
手动绘图、参数交互、练习和本机保存无需联网。
AI 对话需要联网，可在应用内直接接入自己的 DeepSeek Key，也可由管理员预配置环境变量。
课程仍为代表性示例，有限采样和数值图像不能代替数学证明。

【接入 DeepSeek（推荐，应用内）】
1. 启动并登录，打开“教材学习”或“三维曲面实验室”。
2. 点“接入 DeepSeek”，粘贴自己的 sk- 开头的 Key，选择 deepseek-chat 或 deepseek-reasoner。
3. 点“保存 Key”，再点“测试连接”。不需要改文件、不需要重启。
4. Key 加密保存在本机数据库；界面只显示末四位，可随时移除。
5. 练习页的“和 AI 讨论”和“提交答案”也会使用当前生效的 Key。

【可选：系统默认 Key】
1. 打开 backend 文件夹，把 .env.example 复制为 .env。
2. 填写 AI_API_KEY，重启启动窗口；这只作为未接入用户的回退。
3. 其他 OpenAI 兼容服务需设置 AXIOM_AI_PROVIDER=openai、AI_BASE_URL、AI_MODEL。
4. 模型调用按服务商账户规则计费，包内不提供密钥或免费额度。
原始分享包没有携带开发者的密钥、数据库或学习记录。

【保存和分享】
登录后的笔记、作答等保存在本文件夹新建的 data/ 中。
图像场景和部分界面偏好保存在当前浏览器中。
需要迁移记录时，可在停止程序后备份整个使用目录；浏览器中的场景不随文件复制。
转发给其他人请使用原始 ZIP，不要把使用后的 data/ 和 backend/.env 一并压缩分享。
包内保留第三方依赖许可。Python 依赖许可位于 runtime/site-packages 的各包和 dist-info 目录。

当前不包含完整教材课程、任意 PDF 自动解析、跨设备账号服务或公开网站托管。
已在开发机上使用包内环境完成独立启动检查；其他 Windows 电脑仍需实际验证。
