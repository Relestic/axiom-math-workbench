Axiom 公理 · 数学学习工作台 · Windows x64

启动
完整解压 ZIP，双击“启动 Axiom.cmd”。浏览器打开 http://127.0.0.1:5186/ 后即可开始本地学习。保留启动窗口，按 Ctrl+C 可以结束本次运行。包内包含 Python 和运行依赖。端口占用时，可复制 backend/.env.example 为 backend/.env，设置 AXIOM_PORT=5187 后重新启动。
默认免登录。教材、知识卡片、作答和变式题保存在包内 data 目录；当前页面、草稿和笔记等浏览器记录随完整学习存档一起迁移。需要使用服务器账号时，从顶栏头像打开个人设置，展开“高级连接选项”。随包的演示学生账号为 demo@axiom.local，密码为 axiom-demo-2026。管理员演示账号为 admin@axiom.local，密码为 axiom-admin-2026。

阅读与练习
从左栏选择学习主页、学习书桌、知识星图或书架与笔记。学习书桌左栏可切换“讲义定义”“证明思路”“练习与复盘”，右栏黑板可查看二维函数、三维曲面或课本原文。窄屏可在学习内容和黑板之间切换。公式字体、示例讲义和 Hiyori 模型均已随包提供。

在“书架与笔记”拖入 PDF 即可逐页阅读。扫描页会提示需要 OCR。使用个人 Key 可从指定文字页生成卡片，只有定义的页也可生成定义卡。打开知识星图，按书名筛选并选择卡片，点击“去学习书桌研读”可同时查看讲义与对应的 PDF 页。移除 Key 后仍可浏览已保存的卡片与关系。无 Key 可进行证明结构自查和计算题符号批改。Hiyori 可朗读结构反馈。个人 Key 可启用逐步审阅及针对薄弱点的变式题。

伴学与朗读
未设置 Key 时，右栏可以朗读当前步骤或提示，并展示本地讲义中的内容。基础朗读使用系统提供的离线中文语音。开启本机 CosyVoice 服务后，工作台会在朗读时自动检测 127.0.0.1:50000。点击喇叭可切换成只看字幕。
需要模型讲解或 AI 改图时，点击顶栏 AI 徽章，填写个人 DeepSeek Key、选择模型并测试连接。Key 保存在本机后端的 data 目录，Windows 用当前用户的 DPAPI 加密。在右栏向 Hiyori 描述要观察的函数或曲面，她可以切换黑板并修改公式或区间。点黑板的撤销按钮即可还原。模型请求使用个人账号的额度。

迁移学习记录
在“个人设置”中导出完整学习存档（ZIP），到另一台电脑启动工作台后从同一位置导入。存档包含本机数据库、浏览器练习与笔记、场景和上传的教材附件。导入会替换目标机的学习记录，界面会先校验文件并请求确认。个人 API Key 需要在目标机重新设置。
转发给新使用者时请分享原始 ZIP。包内的 licenses、web/companion/licenses 和 runtime/site-packages 保存了各组件的授权说明。
