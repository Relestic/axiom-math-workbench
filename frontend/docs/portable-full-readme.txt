Axiom 公理 · 数学学习工作台 · Windows x64

启动
完整解压 ZIP，双击“启动 Axiom.cmd”。浏览器打开 http://127.0.0.1:5186/ 后即可开始本地学习。保留启动窗口，按 Ctrl+C 可以结束本次运行。包内包含 Python 和运行依赖。端口占用时，可复制 backend/.env.example 为 backend/.env，设置 AXIOM_PORT=5187 后重新启动。
默认免登录。教材、知识卡片、作答和变式题保存在包内 data 目录；当前页面、草稿和笔记等浏览器记录随完整学习存档一起迁移。需要使用服务器账号时，从顶栏头像打开个人设置，展开“高级连接选项”。随包的演示学生账号为 demo@axiom.local，密码为 axiom-demo-2026。管理员演示账号为 admin@axiom.local，密码为 axiom-admin-2026。

阅读与练习
从左栏选择学习主页、学习书桌、知识星图或书架与笔记。学习书桌顶部按书收拢并支持上下翻卡，左栏可切换“讲义定义”“证明思路”“练习与复盘”，右栏黑板可查看二维函数、三维曲面、文字图解或课本原文。窄屏可在学习内容和黑板之间切换。公式字体、示例讲义和 Hiyori 模型均已随包提供。

在“书架与笔记”拖入 PDF 即可逐页阅读，支持文字版与扫描版电子书（扫描页提取时会自动看图识公式并永久缓存在本机数据库）。支持“选整本书”或“接续未提页码”进行 200+ 页快速建书；在学习书桌上开启“翻到卡片自动精配”后，停留满 1.5 秒会自动为当前卡片补齐证明拆解、配套练习题与专属图像。移除 AI 配置后仍可完整浏览已保存的卡片、图像与星图，并进行离线证明结构自查和计算题符号批改。

伴学与 AI 接入
未配置 AI 时，右栏可以朗读当前步骤或提示，并展示本地讲义中的内容。基础朗读使用系统提供的离线中文语音；开启本机 CosyVoice 服务后，工作台会在朗读时自动检测 127.0.0.1:50000。点击喇叭可切换成只看字幕。
需要 AI 提卡、精配或对话改图时，点击顶栏 AI 徽章，任选三种方式之一：
1）DeepSeek（填写个人 API Key，支持 deepseek-flash / deepseek-v4-pro）；
2）ChatGPT / OpenAI（填写个人 API Key，支持预设或自定义模型及可选 HTTPS Base URL）；
3）本机 Codex（免填 Key，直接调用这台电脑已安装并登录的官方 Codex CLI，默认按学习环节自动控制思考强度）。
个人密钥保存在本机 data 目录并由 Windows 当前用户 DPAPI 加密。在右栏向 Hiyori 描述要观察的二维函数、三维曲面或文字图解，她可以切换黑板并修改图像，点撤销按钮即可还原。

迁移学习记录
在“个人设置”中导出完整学习存档（ZIP），到另一台电脑启动工作台后从同一位置导入。存档包含本机数据库、浏览器练习与笔记、场景和上传的教材附件。导入会替换目标机的学习记录，界面会先校验文件并请求确认。个人 API Key 需要在目标机重新设置。
转发给新使用者时请分享原始 ZIP。包内的 licenses、web/companion/licenses 和 runtime/site-packages 保存了各组件的授权说明。
