Axiom 公理 · 数学学习工作台 · Windows x64

启动
完整解压 ZIP，双击“启动 Axiom.cmd”。浏览器打开 http://127.0.0.1:5186/ 后即可开始本地学习。保留启动窗口，按 Ctrl+C 可以结束本次运行。包内包含 Python 和运行依赖。端口占用时，可复制 backend/.env.example 为 backend/.env，设置 AXIOM_PORT=5187 后重新启动。
本地学习空间保存在当前浏览器中。需要使用服务器账号时，在“个人设置”里选择“切换到服务器模式”。随包的演示学生账号为 demo@axiom.local，密码为 axiom-demo-2026。管理员演示账号为 admin@axiom.local，密码为 axiom-admin-2026。

阅读与练习
在教材或图像页打开“讲义与图像对照”。窄屏使用“讲义”“图像”切换面板。顶栏可切换深浅主题。公式字体、示例讲义和 Hiyori 模型随包提供。练习支持符号插入、预览、保存和复盘。知识地图、正反例和证明使用随包的示例课程。

伴学与朗读
未设置 Key 时，右栏可以朗读当前步骤或提示，并展示本地讲义中的内容。基础朗读使用系统提供的离线中文语音。开启本机 CosyVoice 服务后，工作台会在朗读时自动检测 127.0.0.1:50000。点击喇叭可切换成只看字幕。
需要模型讲解或 AI 改图时，点击顶栏 AI 徽章，填写个人 DeepSeek Key、选择模型并测试连接。Key 保存在本机后端的 data 目录，Windows 用当前用户的 DPAPI 加密。模型请求使用个人账号的额度。

迁移学习记录
在“个人设置”中导出完整学习存档（ZIP），到另一台电脑启动工作台后从同一位置导入。存档包含本机数据库、浏览器练习与笔记、场景和上传的教材附件。导入会替换目标机的学习记录，界面会先校验文件并请求确认。个人 API Key 需要在目标机重新设置。
转发给新使用者时请分享原始 ZIP。包内的 licenses、web/companion/licenses 和 runtime/site-packages 保存了各组件的授权说明。
