# 个人记录模块

> 迁移状态：边界已定义；当前页面/服务仍在现有目录，按 `MODULES.md` 的顺序逐步迁入，
> 不复制第二套数据或场景契约。

## 负责范围

笔记、收藏、观察记录、导出。

## 对外接口

`pages/Notes.tsx`、复盘保存入口；`GET/POST/PATCH/DELETE /api/v1/notes`、`/bookmarks`、观察记录接口。

## 数据归属

只允许本人写自己的记录；其他模块通过命令请求保存，不直接改记录表。

## 验收标准

跨用户读写 404；保存失败不丢草稿；导出内容与页面一致。

## 约束

- 只通过模块接口读写；跨模块不能直接改另一个模块的状态。
- ID 使用 `frontend/src/modules/contracts.ts` 中的字符串约定。
- 字段变更必须与后端 Pydantic schema 同一次验收。
- 详细边界见 [`../../../../MODULES.md`](../../../../MODULES.md)。
